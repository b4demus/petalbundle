# Petal Granulizer

Гранулярный эффект для атмосферных текстур.
Ставится на канал микшера: пишет входящий звук в 8-секундный буфер и играет из
него перекрывающиеся гранулы.

## Параметры
| Группа | Параметр | Что делает |
|---|---|---|
| Grains | Density | гранул в секунду |
| | Size | длина гранулы, 10–1000 мс |
| | Jitter | случайность интервала между гранулами |
| | Shape | окно: мягкое (Hann) → жёсткое |
| Time | Position | насколько гранулы отстают от живого звука |
| | Spray | случайный дополнительный разброс по времени |
| | Reverse | вероятность реверса гранулы |
| | Feedback | гранулы снова пишутся в буфер (размазанные хвосты) |
| Pitch | Pitch | общий сдвиг, ±24 полутона |
| | Random | случайный сдвиг каждой гранулы |
| | Pitch Mode | free / octaves / fifths / penta — квантование случайного сдвига |
| Output | Spread | стерео-разброс гранул |
| | Mix / Output | dry/wet и громкость |
| | Freeze | остановить запись и бесконечно гранулировать то, что в буфере |

## Визуализатор
Каждая гранула — цветок: по горизонтали — откуда она читает звук (правее —
ближе к «сейчас»), по вертикали — её питч, бутон раскрывается вместе с окном
гранулы. Отыгравшая гранула рассыпается пыльцой и увядает, уплывая влево.
Внизу — «почва»: громкость входа на той же оси времени.

## Офлайн-проверка движка
```
cargo run --release -p petal-granulizer --example render -- [in.wav] [out.wav]
```
